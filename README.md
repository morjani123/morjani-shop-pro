# Morjani Shop Pro — Phase 1

Premium Blue & White general-store frontend, built with React 19, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Implemented

- Responsive storefront and category browsing
- Search, filters, sorting and product detail modal
- Shopping cart with quantity updates, subtotal and localStorage persistence
- Wishlist with localStorage persistence
- FR / EN / AR language switch with Arabic RTL layout
- Light / dark mode with localStorage persistence
- Mock newsletter feedback
- Demo-only checkout (no real payments)

## Phase 2 (not implemented)

Admin dashboard, product/order management, authentication, backend/database, checkout/payments, inventory synchronization and transactional emails.

Product catalog is demo data. Images are loaded from Unsplash and require an internet connection. Replace with licensed production assets before commercial launch.

This is not a live commerce platform. No real orders or payments are accepted.
